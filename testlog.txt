Testausgabe leer: Die Tests werden nicht ausgeführt oder nicht erkannt. Mögliche Ursachen:
- Das package in get_test.go ist 'test', aber ListTablesHandler ist im package 'table'.
- Die Testdatei wird nicht als Teil des Moduls erkannt.

Lösungsvorschlag:
- Füge in get_test.go einen Import-Alias für das table-Package hinzu (wie in delete_test.go):

import (
    tbl "github.com/a-digi/coco-db/src/table"
    ...
)

- Ersetze alle Vorkommen von 'table.ListTablesHandler' durch 'tbl.ListTablesHandler'.

- Führe dann erneut die Tests aus.
